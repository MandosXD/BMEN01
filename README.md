# Atrial Fibrillation Detection from RR Intervals

This repository contains a Python implementation of an atrial fibrillation (AF) detector developed for the BMEN01 Biomedical Signal Processing course.

The detector uses:
- RR interval difference sequences (\Delta RR)
- Histogram-transition feature extraction
- Sliding-window analysis
- Threshold-based classification

The dataset is based on the MIT-BIH Atrial Fibrillation Database (AFDB) from PhysioNet.
